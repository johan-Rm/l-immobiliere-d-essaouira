# Site public

Application Nuxt 2 pour le catalogue immobilier, les actualités et les pages institutionnelles en français et anglais.

- [Installation et préparation des exports](../SETUP.md)
- [Architecture](../docs/architecture.md)
- [Limites connues](../docs/roadmap.md)

Les pages sont dans `pages`, les composants du thème dans `components/theme-modern-immobilier` et les données d’affichage dans `store`.

Les scripts disponibles sont `dev`, `build`, `start` et `generate`. Il n’existe pas encore de script de tests.
