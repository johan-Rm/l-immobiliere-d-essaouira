# Administration et API

Application Symfony 4.2 : gestion des biens, locations, personnes, médias, contenus et factures. Elle produit aussi les exports du site Nuxt.

- [Installation depuis la racine](../SETUP.md)
- [Architecture](../docs/architecture.md)
- [Limites connues](../docs/roadmap.md)

Les commandes métier sont dans `src/Command`, le modèle dans `src/Entity` et la configuration de l’administration dans `config/packages/easy_admin`.
